# bAD

bAD смотрит компьютеры Windows и показывает их в своей панели. Снимки остаются на вашем сервере.

Сервер и агент сейчас `0.4.0-beta`. Номера лежат в `VERSION` и `agent/VERSION`.

Агент ставится MSI и работает службой `bADagent` из `C:\Program Files\blazerity\bADagent\`. Конфиг, очередь, ключ и логи — в `C:\ProgramData\blazerity\bADagent\`. На сервер он ходит только по `https://`.

Новый ПК оставляет заявку. **«Разрешить»** выдаёт ключ. Пустой номер заводит карточку. Если номер уже есть у живой карточки, кнопка меняет ключ. Отозванную карточку она не возвращает. Пока подпись включена, сервер не принимает снимок без неё.

Сервер умеет обновить себя и отдать агенту новый MSI.

## Сервер

Debian 12, каталог `deploy/debian`:

```bash
BAD_DOMAIN=panel.example.com sudo -E bash install.sh
```

Скрипт ставит PostgreSQL, nginx и службу. Панель сначала открывается по HTTP. Сертификат — в **Параметры → Сертификат**. Первый вход `admin` / `admin`, пароль нужно сменить сразу.

Для разработки из `server/`: Python 3.11, `BAD_DATABASE_URL` на PostgreSQL, затем `uvicorn bad_server.app:app --host 127.0.0.1 --port 8000`.

По шагам: [docs/ste-100.md](docs/ste-100.md).

## Агент

Адрес при установке: `SERVERURL=https://panel.example.com`. После этого машина появляется в заявках, служба сама забирает ключ.

Сборка: в `agent/` команда `dotnet build BadAgent.sln -c Release`. MSI описан в [installer/msi/README.md](installer/msi/README.md).

Обычные команды выполняет служба, и у пользователя, и у администратора. Сама программа `bad` ключ не читает и на сервер не ходит. Если служба не запущена, в колонке будет ошибка.

`bad service` и `bad uninstall` спрашивают обычного пользователя и открывают UAC. Отказ ничего не меняет. В канал службы эти две команды не попадают.

Команды `bad ping` нет. Связь видна в `bad info`.

| Команда | Зачем |
| --- | --- |
| `bad` | Локальный отчёт |
| `bad info` | Версия, сервер, имя, bad_id, модель и связь |
| `bad -r` | HTML-отчёт. Снимок собирает ПК, на сервер несёт служба |
| `bad -c` | Настройка по шагам |
| `bad config` | Настройки. Секреты не печатаются |
| `bad config set` | Один параметр |
| `bad push` | Очередь, снимок, heartbeat |
| `bad update` | Проверить версию и поставить MSI |
| `bad doctor` | Найти поломку и починить локальное |
| `bad service` | Статус, запуск, остановка и перезапуск |
| `bad uninstall` | Снять агент |

`bad doctor` останавливается, если служба не запущена: одна ошибка и подсказка `bad service start`. Нет адреса — одна ошибка. Ключ отклонён — связь есть, обновление не стартует, номер и ключ подписи на месте. Связь есть — сначала очередь, застрявшее обновление и битый файл подписи, потом строка обновления. Настройки и годный ключ подписи doctor не стирает.

Справка: `bad -h`.
