# bAD

Инвентаризация компьютеров Windows в вашей сети. Агент стоит на ПК, сервер хранит снимки и показывает их в панели. Данные остаются у вас.

Сервер — `VERSION` (сейчас 3.0.2). Агент — `agent/VERSION` (сейчас 3.0.3).

## Что входит

| Часть | Где | Стек |
| --- | --- | --- |
| Сервер и панель | `server/` | Python 3.11+, FastAPI, PostgreSQL |
| Агент | `agent/` | .NET 8, служба Windows `badagent` |
| Установщик | `installer/msi/` | WiX, MSI |
| Установка сервера | `deploy/debian/` | Debian 12, nginx |

Агент ходит на сервер только по `https://`. Обновления MSI агент берёт с вашего сервера.

## Сборка для разработки

Сервер: каталог `server/`, Python 3.11, переменная `BAD_DATABASE_URL` на PostgreSQL, затем `uvicorn bad_server.app:app --host 127.0.0.1 --port 8000`. Первый вход в панель: `admin` / `admin`.

Агент: каталог `agent/`, команда `dotnet build BadAgent.sln -c Release`.
