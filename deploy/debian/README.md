# Deploy (Debian 12)

Однострочная установка: `install.sh` — пошагово в [docs/operator-guide.md](../../docs/operator-guide.md).

- С **0.11** сертификаты при установке **не обязательны**: можно сначала HTTP, затем загрузить PEM в панели (**Параметры → Сертификат**). С готовыми файлами на диске — сразу HTTPS.
- База данных — **только Postgres** (`BAD_DATABASE_URL` в `/etc/bad/site.env`). Ключи шифрования (`data_key`, `session_secret`) лежат в `/etc/bad/`, **не** в дампе БД.
- Сразу смените пароль `admin` / `admin`; агентов ставьте только после HTTPS.
- Enrollment-токен не пересылайте в логах `msiexec`; после массовой установки MSI — смените токен в панели.
