# Релизные заметки — сервер 1.5.3 (агент 1.1.0)

Кратко для оператора. Полный путь сопровождения — [operator-guide.md](operator-guide.md).

## Панель и устройства

- Порог **«устарел»** настраивается в **Параметры → Хранение и очистка** (минуты без связи).
- После смены enrollment-токена — показ нового токена и **готовой команды `msiexec`** с кнопкой «Копировать команду».
- На карточке устройства — копирование серийников, IPv4 и MAC.
- Обзор, дашборд и список устройств загружаются быстрее.
- Время в панели и в локальных отчётах `bad` / `bad -r` — в вашем часовом поясе, вид **ЧЧ:ММ:СС ДД.ММ.ГГГГ** (в API и БД — UTC).

## Агент (MSI 1.1.0)

- При установке каталог с `bad` по умолчанию добавляется в PATH (`ADDPATH=1`; отключить: `ADDPATH=0`).
- Обычный пользователь: отчёты `bad` / `bad -r`; настройка — только от администратора (`bad -c`, `config set`).

Старые подробные заметки: [release-notes-1.0.1.md](release-notes-1.0.1.md), [release-notes-1.0.0.md](release-notes-1.0.0.md).
