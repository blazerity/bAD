# Релизные заметки — сервер 1.6.0 (агент 1.1.0)

Кратко для оператора. Полный путь сопровождения — [operator-guide.md](operator-guide.md).

## Почта: сводка вместо письма на каждое изменение

- Изменения по inventory (железо, диски, hostname и т.д.) **по-прежнему видны сразу** в панели (**События**), но **e-mail уходит сводкой**, а не отдельным письмом на каждый снимок.
- **Параметры → Почта и уведомления** — поле **«Интервал сводки, часы»** (1–48, по умолчанию **3**). Письмо — одно на интервал: устройства сгруппированы, в тексте пометки **Появилось** / **Пропало** / **Изменилось**.
- **Регистрация (enroll)** и **stale** в 1.6.0 уходили **сразу**; с **1.7.0** — в общую сводку (см. `release-notes-1.7.0.md`).
- После обновления сервера **старая лента событий в почту не уйдёт** (разовая миграция при старте).

Предыдущий релиз панели: [release-notes-1.5.3.md](release-notes-1.5.3.md).
