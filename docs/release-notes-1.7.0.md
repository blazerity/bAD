# Релизные заметки — сервер 1.7.0

## Почта: единая сводка для всех уведомлений

- **Регистрация нового агента (enroll)** и **устаревшее устройство (stale)** больше не отправляют отдельное plain-text письмо сразу.
- События `device_enrolled` и `device_stale` пишутся в **События** (`device_events`, очередь `mailed_at IS NULL`) и попадают в ту же **HTML-сводку**, что изменения железа и inventory, по интервалу **«Интервал сводки, часы»**.
- Тема письма: `bAD: сводка уведомлений (…)`; в теле — бейджи **Появилось** / **Пропало** / **Изменилось** (enroll — появилось, stale — пропало).
- Тестовая отправка из **Параметры → Почта** показывает примеры enroll, stale и hardware в одном digest.

Агент (`agent/VERSION`) в этом релизе не менялся.
