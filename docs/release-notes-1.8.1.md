# Релизные заметки — сервер 1.8.1

Патч после **1.8.0**. Версия агента не менялась.

## Панель: массовые действия в списке устройств

На странице **Устройства** можно отметить **несколько строк** в таблице и одним действием:

- отправить выбранные ПК в **архив**;
- **добавить один общий тег** ко всем выбранным.

Перед выполнением панель показывает **подтверждение**. Действия доступны только после входа с правами администратора.

## Лимиты регистрации и входа за nginx

Сервер ограничивает частоту **регистрации новых агентов** (`/v1/enroll`) и **попыток входа** в панель. С **1.8.1** при штатной схеме (приложение за **nginx** на том же хосте) в расчёт берётся **IP посетителя**, а не адрес прокси на localhost.

Шаблон nginx из установки bAD уже передаёт нужный заголовок (`X-Real-IP`). Если перед панелью стоит **свой** обратный прокси, настройте передачу реального IP так же, иначе лимиты могут срабатывать неверно. При превышении лимита ответ **429** — подождите минуту и повторите.
