# Релизные заметки — сервер 2.0.1

Линия версий сервера выровнена с агентом (**2.0.x**). Агент в этом теге: **2.0.1** ([release-notes-agent-2.0.1.md](release-notes-agent-2.0.1.md)).

## Панель Bolt

В **main** влита вёрстка с бывшей ветки **beta**: обновлённые **Обзор**, **Дашборд**, списки **Устройства** и **События**, карточка устройства и страницы **Параметров** — единый стиль **Bolt** (сетки, карточки, поиск с очисткой). Поведение API и агентов не менялось.

## Снять агент с компьютера

На карточке устройства (admin): **«Снять агент с компьютера»**. Оператор вводит **имя узла** для подтверждения; сервер ставит команду в `meta` устройства. При **следующем heartbeat** агент **2.0.1+** получает `actions.uninstall` и запускает тихое удаление MSI (`msiexec /x`). Это **не** отзыв ключа и **не** удаление карточки в панели — только снятие программы с ПК. Пока команда не ушла, её можно отменить. Подробнее: [operator-guide.md](operator-guide.md), [tz-remote-uninstall.md](tz-remote-uninstall.md).

## Режим QA для разработки

Переменная **`BAD_QA_UI=1`** (только lab): упрощает скриншоты панели на `http://127.0.0.1:8000` — без баннера HTTP, мастера «первый запуск» и принудительной смены пароля. **В production не включать.** Подробности: [server/README.md](../server/README.md).
