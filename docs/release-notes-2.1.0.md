# Релизные заметки — сервер 2.1.0

Рекомендуемый агент: **2.0.2** ([release-notes-agent-2.0.2.md](release-notes-agent-2.0.2.md)). Сначала обновите сервер, затем MSI агентов.

## bad-id — короткий код устройства

У каждого ПК в панели появился **bad-id** (например `BAD-K7Q2MP`): его видно в списке и в шапке карточки, можно **скопировать**. Ссылки на карточку ведут на `/devices/BAD-…`; старые закладки с длинным `device_id` по-прежнему открываются.

В API в ответах `GET /v1/devices` добавлено поле **`bad_id`**. Регистрация агентов и интеграции по-прежнему используют **`device_id`**.

## Каталог устройств и дашборд

- **Массовые действия в таблице сняты** (чекбоксы и «добавить тег всем»). Архив и теги — **на карточке** одного устройства, как раньше.
- Новые **фильтры** (чипы над таблицей): ОС, объём ОЗУ, диски, семейство CPU, вендор CPU, версия агента, **«Онлайн»** (`fresh=ok`). Клик по сегменту **дашборда** открывает тот же фильтр.
- В списке: колонки **ОЗУ**, **ОС** (с подписью `bAD x.y.z`), **IP** одной строкой с копированием, **пользователь** («в системе» / «последний»).
- Экспорт CSV: в конец добавлена колонка **`bad_id`**.

## Обзор и навигация

Порядок слева: **Обзор → Дашборд → Устройства → События**. С Обзора убраны дубли блоков версий агента (они на дашборде). Добавлена лента **«Недавнее железо»** (критичные изменения железа, без USB).

Глобальный поиск на Обзоре находит ещё и **пользователей Windows** (по имени на ПК), не учётки панели.

## События

- USB-накопители и флешки — отдельные типы **`usb_added` / `usb_removed`** (низкая важность), не «критичное» снятие диска.
- Системные диски: снятие fixed-диска по-прежнему **критично**; подключение — средняя важность.
- Пересмотрена **важность** ряда типов (например смена IP и reboot — ниже по умолчанию; снятие CPU или планки ОЗУ — выше). В ленте по умолчанию по-прежнему скрыт «шум» (`low`).

## Перезагрузка и снятие агента

- Бейдж **«ожидает перезагрузку»** показывается только при агенте **2.0.2+** и только если в снимке есть **конкретные причины** (обновления Windows / CBS), не из-за «мусора» в реестре.
- Подтверждение **«Снять агент»**: hostname, либо **bad-id**, либо служебный `device_id` — любое точное совпадение из подсказки.
