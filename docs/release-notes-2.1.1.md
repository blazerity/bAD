# Релизные заметки — сервер 2.1.1

Хотфикс дашборда. Агент без изменений (**2.0.2**).

## Поколения CPU

- Исправлено определение **Core Ultra**: строки вида `Core(TM) Ultra` больше не схлопываются в один куб **«Intel»**.
- Семейство для дашборда и фильтра считается заново из `cpu_name` (не нужен новый inventory).
- Добавлен Xeon Cascade Lake (например Gold 62xx). Голый ярлык «Intel» на treemap не показывается.

## Модели устройств

На дашборде — два блока кубиков по тому же принципу, что поколения CPU:

- **Модели ноутбуков** (`chassis=laptop`)
- **Модели ПК** (`chassis=desktop`)

Клик открывает каталог с фильтром модели. Размер куба пропорционален числу устройств (самый частый — самый большой).
