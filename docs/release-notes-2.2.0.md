# Релизные заметки — сервер 2.2.0

Редизайн дашборда по UI/UX-аудиту. Агент без изменений (**2.0.2**).

## Оперативный пульт

- KPI: **Всего ПК / В сети / Требуют обновления / Инциденты** (без путаницы «онлайн/устарели»).
- Сетка 7+5: слева динамика событий и комплаенс версий, справа лента инцидентов и структура парка.
- **События по дням:** столбцы с сеткой, осями, переключатель 7/14/30 д, tooltip (критичные / предупреждения).
- **Лента инцидентов:** hostname, пользователь, бейджи CRITICAL/WARNING, агрегация повторов `×N`, относительное время.
- **Отставание версий:** целевая версия, глубина (−N релиз / Критично), CTA «волна обновления».
- **Состояние парка:** сеть и комплаенс агента раздельно; архив только если > 0.

## Данные и визуализации

- Нормализация ОС (`Windows 10 Pro` / `Enterprise`, fallback «Не определена»), число ПК в центре donut.
- Treemap заменён на **ТОП-5** горизонтальных баров (CPU, ноутбуки, СБ) + «Остальные» с модалкой.
- Минимальная высота полос ОЗУ/дисков для кликабельности.
