# Релизные заметки — сервер 2.2.5

Поиск по всем серийникам парка. Агент без изменений (**2.0.2**).

## Поиск

- Находятся устройства по серийникам **ПК, BIOS, платы, дисков, мониторов и модулей ОЗУ**.
- В meta кэшируются `disk_serials` / `monitor_serials` / `ram_serials` / `search_serials` при инвентаризации.
- Для уже собранных снимков поиск смотрит и в `inventory_snapshots.payload_json` (без ожидания нового inventory).
- В выдаче видно, какой тип серийника совпал (например «монитор: …»).
