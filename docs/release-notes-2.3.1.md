# Релизные заметки — сервер 2.3.1

UI под Full HD и аккуратнее таблицы.

## Панель

- Ширина контента **1600px** (было ~1200 / 1280) — нормально на 1920×1080 с полями по бокам.
- Лента событий: тумблер **Критичные / Все**, hostname/user с фиксированной шириной и ellipsis.
- Устройства: `table-layout: fixed`, hostname и пользователь не раздувают колонки.
- Убраны текстовые приписки «в системе» / «последний» у пользователя (рамка цвета остаётся).

Предыдущий релиз: [release-notes-2.3.0.md](release-notes-2.3.0.md).
