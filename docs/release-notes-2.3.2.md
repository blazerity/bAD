# Релизные заметки — сервер 2.3.2

Правки вёрстки после 2.3.1 и логика почтовой сводки.

## Исправления UI

- **Устройства:** колонки снова совпадают с заголовками (`display:block` на `<td>` ломал таблицу).
- **Обзор:** сайдбар (зона действий / риски / каталог) свёрнут в «Сервер bAD»; динамика и лента на всю ширину.
- Баннер «нет критичных» — только при фильтре «Критичные», сверху ленты (и больше не просвечивает из‑за CSS).
- **Параметры:** форма шире; расписание сводки компактнее (дни в ряд).

## Почта

- Убрано окно lookback: в слот уходят **все неотправленные** события выбранных типов (накопленные вне расписания тоже).
- В теме письма короткий timestamp: `bAD: сводка 29.10 18:30 · …`.
