# Релизные заметки — сервер 2.3.3

Таблица устройств: короче ОС, ОЗУ как на дашборде, CPU с переносом.

## Устройства

- ОС без префикса «Майкрософт» / Microsoft → `Windows 11 Pro` и т.п. (колонка уже, IP влезает).
- ОЗУ: номинал **8 / 16 / 32 ГБ** (+ **DDR4/DDR5**, если есть в inventory).
- CPU: перенос строк, без обрезки одной длинной строкой.
