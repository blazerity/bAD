# Релизные заметки — сервер 2.3.4

Правки по ревью UI: таблица устройств на 2K, компактные фильтры, короткий CPU.

## Устройства

- Колонки таблицы: фиксированная вёрстка, узкая ОЗУ, полный первый IPv4 (+N при нескольких), больше места модели и пользователю.
- CPU в списке: короткая подпись без ® и частоты (@ GHz).
- Фильтры: одна строка (поиск, парк, основные селекты); «Ещё фильтры» для тега, волны, вендора, агента, архива; CSV справа.
- Ширина контента: до **1760px** (main/footer).

## Прочее

- События: сбалансированные колонки таблицы.
- Обзор: сетка ленты событий (host/user/summary).
