# Релизные заметки — сервер 2.3.6

Производительность веб-панели при скролле (Chrome / iGPU).

## Что изменилось

- Убран `background-attachment: fixed` и fixed-слой ambient-шума (фон остаётся «mica», но рисуется дешевле).
- `backdrop-filter` снят с карточек, таблицы устройств, фильтров и прочих больших блоков — остался лёгкий blur только у липкой шапки.
- Карточки чуть плотнее по фону (0.94), визуально почти как стекло, без постоянной перерисовки blur.
- Hover на дашборде: `transform` / border, без анимации теней.
- Таблица: `content-visibility: auto` на строках + `contain` на карточке списка.

Анимации page-in / hover lift / dash-reveal сохранены.

## Параметры

- Все подпункты: формы, meta и таблицы на одну ширину колонки (убран узкий `56rem` только у `.settings-form`).
