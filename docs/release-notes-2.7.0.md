# Релизные заметки — сервер 2.7.0

Код устройства в панели и подключение программ, которым нужно только читать карточки.

## Что изменилось

- **bad-id** теперь из 10 символов. Сервер считает его из идентификатора компьютера. При первом запуске после обновления старые шестисимвольные коды заменяются. Повторный запуск их не меняет. Закладка со старым коротким кодом больше не открывается. Закладка с `device_id` открывается.
- **Параметры → Интеграции.** Программа сама присылает заявку. Пока её не подтвердите, карточки она не читает. После подтверждения программа один раз забирает ключ только на чтение. В панели ключ не показывается. В списке видно, когда и сколько раз программа успешно читала карточки. **Отозвать** закрывает доступ.

Агент и его версия не менялись.
