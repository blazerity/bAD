# Релизные заметки — агент 1.3.0 (MSI)

Команды на ПК с агентом разделены:

- **`bad push`** — только **синхронизация с сервером**: очередь, снимок inventory, heartbeat (подтянуть политику и настройки).
- **`bad update`** — **проверка и установка** новой версии MSI с сервера (self-update).

Флаг **`bad push --update` снят**; при попытке использовать его CLI подскажет вызвать **`bad update`**. Версия сервера для этого релиза не обязательна; см. [agents.md](agents.md) и [operator-guide.md](operator-guide.md).
