# Релизные заметки — агент 1.3.1 (MSI)

Патч после **1.3.0** ([release-notes-agent-1.3.0.md](release-notes-agent-1.3.0.md)).

## Ожидание перезагрузки (pending reboot)

Признак **«нужна перезагрузка»** в снимке inventory считается **строже**: учитываются стандартные ключи Windows и **осмысленные** операции переименования файлов при перезагрузке (PFRO). Временные пути и мусор в реестре **не** помечают ПК как «ждёт reboot».

## Серийный номер NVMe-диска

Если у диска в WMI пустой или бессмысленный serial, агент пробует **запасной идентификатор** из **Microsoft Storage** (`MSFT_PhysicalDisk.UniqueId`): префиксы **eui.** и **nguid.** — так надёжнее на части NVMe, где классический serial не приходит.

Сервер **1.10.x** и новее; для полной картины по дубликатам на панели желателен сервер **1.10.1**.
