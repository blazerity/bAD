# Релизные заметки — агент 2.0.1 (MSI)

Патч semver после **2.0.0**: установка, служба **`badagent`**, каталог **`%ProgramFiles%\blazerity\bad agent\`**, CLI и миграция с 1.x — без изменений. См. [release-notes-agent-2.0.0.md](release-notes-agent-2.0.0.md).

**Удалённое снятие:** если панель (сервер **2.0.1+**) запросила снятие, в ответе heartbeat приходит `actions.uninstall` — агент запускает `msiexec /x` для своего MSI и завершает службу. Нужен сервер с поддержкой команды на карточке устройства.

Рекомендуемый сервер панели: **2.0.1** ([release-notes-2.0.1.md](release-notes-2.0.1.md)).
