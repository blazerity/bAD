# Релизные заметки — агент 2.0.2 (MSI)

Патч после **2.0.1**. Установка, служба **`badagent`**, каталог и CLI — как в [release-notes-agent-2.0.0.md](release-notes-agent-2.0.0.md).

## Пользователь Windows

- **`logged_on`** — только кто сейчас за консолью; пустая сессия — пустой список, не «затирать» данные на сервере.
- **`last_interactive`** — из реестра последнего входа (если есть), иначе текущий пользователь. Панель **2.1.0** показывает «в системе» / «последний» по этим полям.

## Ожидание перезагрузки

- **`pending_reboot`** — только при реальной необходимости: ключ **Windows Update** или **непустой** CBS `RebootPending`.
- В снимок добавлен список **`pending_reboot_reasons`** (`windows_update`, `cbs`). Временные файлы PFRO больше **не** считаются причиной.

## Диски (для сервера 2.1.0)

В inventory добавлены **`removable`** и **`pnp_device_id`** у дисков — сервер точнее отличает флешку/USB от системного диска в событиях.

Рекомендуемый сервер: **2.1.0** ([release-notes-2.1.0.md](release-notes-2.1.0.md)).
