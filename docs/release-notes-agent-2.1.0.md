# Релизные заметки — агент 2.1.0 (MSI)

Минор после **2.0.2**: чище каталог установки и снятие из CLI.

## Каталог `bin`

- Добавлен **`bin\uninstall.cmd`** — запуск снятия из папки установки.
- Упаковка `bin\` (single-file) в 2.1.0 заменена в **2.1.1** на framework-dependent + папки `ms\` / `lib\` — см. [release-notes-agent-2.1.1.md](release-notes-agent-2.1.1.md).

## CLI

- **`bad uninstall`** (опечатка `unistall` тоже принимается) — снятие MSI через `msiexec` (нужны права администратора).
- Подтверждение по умолчанию; без вопросов: **`bad uninstall -y`**.

Сервер: любая актуальная 2.2.x. После выкладки MSI в GitHub Release синхронизируйте зеркало на сервере.
