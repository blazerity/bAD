# Релизные заметки — агент 2.1.3 (MSI)

Патч после **2.1.2**: исправление ручного `bad update` / `bad uninstall` из консоли.

## Что исправлено

На ПК с агентом, запущенным через **`bad.cmd`** (`bad update` от администратора), Windows Installer (Restart Manager) слал **CTRL+C** в ту же консоль. Появлялось «**Завершить выполнение пакетного файла (Y/N)?**» — и при **Y**, и при **N** обновление срывалось.

Теперь msiexec стартует **отложенно и вне консоли** (короткий helper в `%TEMP%`), а CLI сразу выходит, чтобы `bad.cmd` успел завершиться до замены файлов.

## Обходной путь для 2.0.2 / 2.1.x до 2.1.3

Пока на машине старая сборка:

1. Обновление **со службы** (автопроверка / кнопка в панели) — без `bad.cmd`, обычно работает.
2. Или вручную: скачать MSI с сервера и  
   `msiexec /i bad-agent-<ver>.msi /qn /norestart`
3. Или вызвать exe напрямую (без батника):  
   `"%ProgramFiles%\blazerity\bad agent\bin\BadAgent.exe" update`  
   — вопрос про пакетный файл не появится, но CTRL+C от RM всё ещё может мешать; надёжнее пункт 1 или 2.

После выкладки **2.1.3** в зеркало повторный `bad update` с 2.1.3 уже безопасен.

## Упаковка

Без изменений: self-contained, `bin\` + `ms\` / `lib\`.
