# Агент 2.3.0

Что изменилось по сравнению с **2.0.2**.

## Обновление

- Компьютеры с **2.0.2** переходят на **2.3.0** обычным обновлением с сервера.
- Перед заменой файлов служба останавливается. Перезагрузка не нужна.
- Настройки, идентификатор устройства и ключ сохраняются. Повторная регистрация не нужна.

## Программа

- Файлы по-прежнему лежат в одной папке `bin`. Отдельно ставить .NET не нужно.
- Снять агента можно командой `bad uninstall` или файлом `uninstall.cmd` в папке установки. Для тихого снятия: `bad uninstall -y`.
- Ручное обновление из консоли больше не спрашивает, прерывать ли пакетный файл.

Предыдущие заметки агента: [2.0.2](release-notes-agent-2.0.2.md).
