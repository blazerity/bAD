# Агент 2.3.1

Сборка после **2.3.0**. Поведение обновления то же.

При запуске агент удаляет копии установщика старше часа из временной папки Windows (`bad-agent-update`). Файл, который сейчас ставится, не трогает. Раньше каждая неудачная попытка оставляла папку примерно на 28 МБ.

Остальное — как в [2.3.0](release-notes-agent-2.3.0.md).
