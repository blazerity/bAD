# STE-100

Инструкция для панели bAD 3.1.3. Каждый номер — одно действие. Имена кнопок совпадают с панелью.

Новый ПК подключается заявкой. Панель код установки не выдаёт.

## Сервер

1. На Debian 12 откройте каталог `deploy/debian` этого репозитория.
2. Выполните `BAD_DOMAIN=<домен> sudo -E bash install.sh`.
3. Откройте в браузере `http://<домен>/login`.
4. Введите логин `admin` и пароль `admin`.
5. Откройте **Параметры → Смена пароля**.
6. В поле **«Текущий пароль»** введите `admin`.
7. В поле **«Новый пароль»** введите новый пароль длиной не меньше 8 символов.
8. В поле **«Подтверждение»** введите тот же новый пароль.
9. Нажмите **«Сохранить пароль»**.
10. Откройте **Параметры → Сертификат**.
11. В поле **«Сертификат (PEM)»** выберите файл сертификата.
12. В поле **«Закрытый ключ (PEM)»** выберите файл закрытого ключа.
13. Нажмите **«Установить сертификат»**.
14. Откройте `https://<домен>/login`.

## Подпись снимка

15. Откройте **Параметры → Обновления агента**.
16. Включите флажок **«Требовать подпись снимка»**.
17. Нажмите **«Сохранить»**.

## Новый ПК

18. На ПК Windows выполните от имени администратора `msiexec /i bad-agent-3.1.3.msi SERVERURL=https://<домен>`.
19. Откройте в панели раздел **Устройства**.
20. В блоке **«Заявки на подключение»** дождитесь строки этого ПК со статусом **«Ожидает разрешения»**.
21. В этой строке нажмите **«Разрешить»**.
22. На этом ПК выполните от имени администратора `bad push`.

Команда из шага 22 забирает ключ подписи и отправляет подписанный снимок. Повторная установка на тот же ПК снова показывает заявку на ту же карточку.

Список программ собирается сам. Чтобы его выключить, на карточке откройте **«Параметры агента»**, в поле **«Собирать ПО»** выберите **«нет»** и нажмите **«Сохранить настройку»**.

## HTML-отчёт с сервера

23. На этом же ПК выполните `bad -r`.
24. Откройте в браузере файл, путь к которому команда напечатала строкой `HTML-отчёт записан:`.

Если ПК уже подключён к серверу, файл собирает сервер. Снимок в базу эта команда не пишет.

## Разбор минидампа

25. Откройте в панели карточку этого устройства.
26. В левом списке разделов нажмите **«Минидампы BSOD»**.
27. Под файлом с расширением `.dmp`, имя которого не `Memory.dmp`, нажмите **«Разобрать»**.
28. На ПК выполните от имени администратора `bad push`.
29. Обновите карточку устройства в браузере.
30. В блоке того же файла прочитайте поле **«Причина»**.

Сервер читает заголовок дампа и не хранит тело файла.

## Обновление уже установленного агента

Эти шаги — для ПК, где агент уже стоит. Обновления включены, цель — последняя версия в каталоге, у файла в каталоге есть SHA256.

31. Откройте **Параметры → Обновления агента**.
32. В блоке **«Загрузить установщик вручную»** выберите файл `bad-agent-3.1.3.msi`.
33. Нажмите **«Добавить в каталог»**.
34. В каталоге версий проверьте, что у `3.1.3` в колонке **SHA256** есть значение.
35. На карточке ПК откройте **«Параметры агента»** и проверьте строку обновлений: **вкл**, цель **latest**.
36. Дождитесь, пока в поле **«Версия агента»** на этой карточке станет `3.1.3`.

Кнопка из шага 33 кладёт файл в каталог сервера `/var/lib/bad/agent-updates/3.1.3/bad-agent-3.1.3.msi` и записывает SHA256. Уже установленный агент забирает эту версию сам, когда обновления включены и цель — latest.

Установщик не стирает файл настроек и не стирает ключ этого ПК. Если старая подпись не подходит к снимку, агент удаляет её и отправляет снимок ещё раз.

## Проверка связи

37. На ПК выполните от имени администратора `bad ping`.
38. Прочитайте строку **«Связь есть.»** или **«Связи нет.»**.
