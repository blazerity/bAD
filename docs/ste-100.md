# STE-100

Инструкция для панели bAD 3.0. Каждый номер — одно действие. Имена кнопок совпадают с панелью.

Новый ПК подключается заявкой.

## Сервер

1. На Debian 12 откройте каталог `deploy/debian` этого репозитория.
2. Выполните `BAD_DOMAIN=<домен> sudo -E bash install.sh`.
3. Откройте в браузере `http://<домен>/login`.
4. Введите логин `admin` и пароль `admin`.
5. Откройте **Параметры → Смена пароля**.
6. В поле **«Текущий пароль»** введите `admin`.
7. В поле **«Новый пароль»** введите новый пароль длиной не меньше 8 символов.
8. В поле **«Подтверждение»** введите тот же новый пароль.
9. Нажмите **«Сохранить пароль»**.
10. Откройте **Параметры → Сертификат**.
11. В поле **«Сертификат (PEM)»** выберите файл сертификата.
12. В поле **«Закрытый ключ (PEM)»** выберите файл закрытого ключа.
13. Нажмите **«Установить сертификат»**.
14. Откройте `https://<домен>/login`.

## Флажки регистрации и подписи

15. Откройте **Параметры → Обновления агента**.
17. Включите флажок **«Требовать подпись снимка»**.
18. Нажмите **«Сохранить»**.

## Клиент без общего токена

19. На ПК Windows выполните от имени администратора `msiexec /i bad-agent-3.0.0.msi SERVERURL=https://<домен>`.
20. Откройте в панели раздел **Устройства**.
21. В блоке **«Заявки на подключение»** дождитесь строки этого ПК со статусом **«Ожидает разрешения»**.
22. В этой строке нажмите **«Разрешить»**.
23. На этом ПК выполните от имени администратора `bad push`.

Команда из шага 23 забирает ключ подписи и отправляет подписанный снимок.

## HTML-отчёт с сервера

24. На этом же ПК выполните `bad -r`.
25. Откройте в браузере файл, путь к которому команда напечатала строкой `HTML-отчёт записан:`.

Если на ПК заданы `server_url` и `api_key`, файл собирает сервер. Снимок в базу эта команда не пишет.

## Разбор минидампа

26. Откройте в панели карточку этого устройства.
27. В левом списке разделов нажмите **«Минидампы BSOD»**.
28. Под файлом с расширением `.dmp`, имя которого не `Memory.dmp`, нажмите **«Разобрать»**.
29. На ПК выполните от имени администратора `bad push`.
30. Обновите карточку устройства в браузере.
31. В блоке того же файла прочитайте поле **«Причина»**.

Сервер читает заголовок дампа и не хранит тело файла.

## Обновление агента 2.3.1

Эти шаги — для ПК, где уже стоит агент 2.3.1. Цель версии — `latest`, обновления включены, у файла в каталоге есть SHA256.

32. Откройте **Параметры → Обновления агента**.
33. В блоке **«Загрузить установщик вручную»** выберите файл `bad-agent-3.0.0.msi`.
34. Нажмите **«Добавить в каталог»**.
35. В каталоге версий проверьте, что у `3.0.0` в колонке **SHA256** есть значение.
36. На карточке ПК с агентом 2.3.1 откройте **«Параметры агента»** и проверьте строку обновлений: **вкл**, цель **latest**.
37. Дождитесь, пока в поле **«Версия агента»** на этой карточке станет `3.0.0`.

Кнопка из шага 34 кладёт файл в каталог сервера `/var/lib/bad/agent-updates/3.0.0/bad-agent-3.0.0.msi` и записывает SHA256. Агент 2.3.1 забирает эту версию сам, когда цель — `latest` и обновления включены.

## Агент 3.0.3

Агент 3.0.3. ПК с агентом 2.3.1 забирает эту версию сам, когда обновления включены и цель — latest. Файл настроек и ключ устройства установщик не стирает. Шагов на ПК нет. Если старый файл подписи мешает снимку, агент удаляет его сам и отправляет снимок ещё раз. Команда bad ping от имени администратора показывает «Связь есть.» или «Связи нет.».
