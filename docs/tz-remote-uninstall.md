# ТЗ: снятие агента с компьютера (remote uninstall)

Краткое описание поведения для операторов и разработчиков. Версия панели: **2.0.1+**, агент: **2.0.1+**.

## Цель

Дать администратору панели команду **снять установленный MSI агента с Windows-ПК**, не удаляя учётную запись устройства в базе и не отзывая API-ключ вручную (это отдельные действия).

## Не входит в scope

| Действие | Что делает |
|----------|------------|
| **Отозвать ключ** | Блокирует доступ агента к API; запись в панели остаётся |
| **Удалить устройство** | Удаляет строку и данные из БД |
| **Снять агент с компьютера** | Только удаление программы на ПК; карточка в панели **остаётся** |

## Сценарий оператора

1. Открыть карточку устройства → блок администратора.
2. Нажать **«Снять агент с компьютера»**.
3. В поле **Подтверждение** ввести **точное** значение из подсказки: **hostname**, **bad-id** (`BAD-…`) или **`device_id`** — любое одно совпадение. Дополнительно браузер спрашивает подтверждение с тем же текстом.
4. Сервер записывает в `devices.meta`: `uninstall_requested_at` (UTC).
5. При **следующем успешном heartbeat** сервер в ответе ставит `actions.uninstall: true` один раз и переносит метку в `uninstall_sent_at`.
6. Агент находит свой продукт в реестре Uninstall, запускает **`msiexec /x … /qn`**, останавливает службу и выходит.

## Состояния в панели

| Метка | Смысл |
|-------|--------|
| **Удаляется** | Команда ждёт heartbeat |
| **Команда отправлена** | `uninstall` уже отдан агенту |
| **Не дошло** | За **7 суток** heartbeat с активной командой не был; запрос сброшен |

До отправки команды на ПК можно **отменить** запрос (кнопка на карточке).

## Ограничения

- Только **web admin** (сессия панели).
- Для отозванного устройства (`revoked`) новую команду не ставят.
- Агент **старше 2.0.1** команду не выполняет (поле в heartbeat игнорируется на клиенте).
