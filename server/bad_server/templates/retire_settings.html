Сервер после этой кнопки продолжает работать. Повторное нажатие не ставит приказ тем, кому он уже ушёл или ещё висит.

Снять сервер

Кнопка доступна сразу. Число выше показывает, сколько карточек приказ ещё не забрали: эти агенты останутся на ПК. Снос останавливает службы bAD, удаляет /opt/bad, /var/lib/bad, /etc/bad, сайт nginx и данные кластера Postgres, затем создаёт пустой кластер. Пакеты Postgres, nginx и Python остаются. Сертификаты вне /etc/bad не трогаются.
